# Relato de vulnerabilidades

Para relatar uma possível vulnerabilidade do A&B Produção, use o contato técnico **tech@grupotrio.com.br**. Não publique credenciais, contratos, dados de clientes ou instruções de exploração com informações privadas em issues abertas.

Inclua a descrição, o componente afetado, a versão observada e passos de reprodução com dados fictícios. Não envie senhas ou chaves de API.

O repositório é um snapshot; a versão implantada deve ser identificada durante a análise. Não há matriz de versões suportadas nem prazo de atendimento formalizado neste documento.
